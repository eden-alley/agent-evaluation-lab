# 项目文档目录

这份目录先帮助你理解项目，再按需查操作。当前产品是 **Agent 评测工作台**；本轮先看清缺陷、架构和取舍，不新增评测流程。

## 从这里开始

| 顺序 | 文档 | 读完能回答什么 |
| --- | --- | --- |
| 1 | [项目现状与取舍](PROJECT_REVIEW.md) | 题集、执行、评分各有什么缺口？哪些方向已确认，哪些还没决定？ |
| 2 | [架构与代码地图](../ARCHITECTURE.md) | 一道 U05 从启动到判分、归档、展示经过哪些代码？数据在哪里？ |
| 3 | [产品定位与边界](../PRODUCT.md) | 这个工作台服务谁、核心是什么、哪些内容已排除出产品方向？ |
| 4 | [开源实现参考](OPEN_SOURCE_REFERENCES.md) | 成熟项目的哪些机制值得借鉴？适配成本和未验证之处是什么？ |

先沿一道题看输入、执行、评分和证据，不要求一次读完所有文档。上述页面区分**当前实现、已确认目标、待选建议**；目标不表示代码已经完成。
