# U03 归档复盘

本例依据 2026-11-10 的真实运行归档完成复盘，复盘方法为 v0.1.0 草稿。新增模型请求为 0。原题使用 DeepTutor 隔离源码构造失联恢复缺陷，运行预算为 60 次请求，第 30 次作为观测点。选取的事件、文件指纹及归档哈希保存在 [证据摘录](u03-evidence.json)。

## 停在哪里

最后证实的阶段为复现故障，下一项关键动作是修改业务源码。

- 到第 30 次请求时，模型查阅源码并生成了临时切片。
- 第 48 次请求后的事件 159 运行公开测试，工具回显以 exit 0 开头，测试正文为 waiting_input 与 failed 不相等，最终显示 FAILED。
- 事件 197 是一次读取临时源码的返回。事件 198 记录达到 max_steps 后停止。
- 最终业务文件 deeptutor/app/service.py 与初始文件的 SHA-256 一致。工作区残留 .tmp_a.py，未提交 report.md。独立验收四项中两项失败，分别是失联后解除会话阻塞、终止事件保存及发布。

这些材料能确定本次交付停在何处。代码阅读能力、工具接口、任务推进策略和模型本身都可能影响后续行为，当前记录不足以区分各自贡献。
