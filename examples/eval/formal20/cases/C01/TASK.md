# C01 · 定位 /resume 更换模型后被拒的调用链

## 第 1 轮

团队在任务中断后换了模型，再在同一终端工作区输入 /resume，得到「检查点源码、工作区、工具、模型或额度配置不匹配」。也有人仅替换工具后遇到同样的提示。已有检查点还要保留。

从 CLI 的 /resume 入口沿真实源码追踪，说明检查点在哪读取、怎样判断模型与工具匹配、通过后在哪恢复状态并继续。指出至少一种与绑定无关的拒绝恢复条件。只交付 resume-analysis.json，给定源码只读，保持其他文件原样。不需要改配置、调用模型或实际续跑。

输出对象含 verification（字符串，说明静态源码核对或另外做了何种验证）及 dispatch、disk_read、binding_rejection、resumption 四个对象。每个对象含 explanation（说明）和 refs（引用数组，每项含 file 与 line，按冻结源码的文件名和 1 起始行号定位）。绑定拒绝同时引用比较处和绑定生成处；CLI 说明给出用户指令进入和转发的位置。
