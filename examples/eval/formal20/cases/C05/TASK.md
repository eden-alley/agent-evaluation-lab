# C05 · 修复后补一份确实能检出原缺陷的回归测试

## 第 1 轮

计算器支持合法RPN表达式的加减乘除。现有测试通过，但 `9 2 -` 没有返回7。修复实现，在 tests/test_regression.py 新增标准库 unittest 回归测试，覆盖减法及除法的操作数顺序。该新增测试单独在原缺陷版本上应发生断言失败，在修复版上通过；不能改已有测试或只断言程序不崩溃。

先定位并解释实际运行路径中的原因，再修复与缺陷直接相关的业务代码。
不得修改公开测试、输入样例、配置、许可证或 legacy 中的历史实现，也不要引入第三方依赖。
允许在 tests/test_regression.py 新增回归测试；不得修改已有测试。
完成后实际运行 `python -B -m unittest discover -s tests -v`，并在 report.md 写出定位依据、修改文件、测试命令与真实结果。
不同正确修法允许；不要求复现某个隐藏补丁。范围外文件必须保持原字节，业务代码中的无关修改会单独复核。
