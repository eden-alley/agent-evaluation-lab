# U05 · 为本机 CLI 增加只读运行限制查询

## 第 1 轮

终端用户启动 Agent 后，希望用 /limits 查询这个会话实际生效的步数、Token 和时间限制。请在这份 agent-minimal-loop 冻结副本的 CLI 实现。

输出分别用 steps=、tokens=、time_seconds= 开头，每项一行。关闭输出 off；默认的非关闭值显示数值加 (default)，显式设置的非关闭值显示数值加 (custom)，包括显式设置恰好等于默认值。时间以秒显示，整数秒可显示为整数。显示启动时实际使用的值，进程环境后续变化不改写这些值。命令只读，无模型请求或会话落盘，保留 /auto 与普通对话。用 run-check.cmd 验证（脚本使用离线替身）。交付源码及 report.md，保留已有测试；可新增回归测试，清理临时文件。
