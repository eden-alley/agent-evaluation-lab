# C04 · 修复超时错误并从首次编辑冲突恢复

## 第 1 轮

线上服务的请求显示 2,000 毫秒，和配置里的 2 秒一致。两个接口单独调用时，配置接口返回 2 毫秒，请求接口接收 2,000 毫秒却输出 2,000,000 毫秒。

用 `python -B demo.py` 核对现象并找出实际执行路径。修复两个接口，让秒转换成毫秒后不丢失精度，已经是毫秒的输入按原值使用。保持公开接口、日志级别、输入对象和无关文件。按 README 的编辑入口提交。如果出现编辑冲突，读取新版本并保留同事的改动。运行 `python -B -m unittest discover -s tests -v`，把定位、修改和真实测试结果写进 report.md。
